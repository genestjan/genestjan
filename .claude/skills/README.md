# Project skills

Third-party Claude Code skills vendored into this repo so every session
(including cloud sessions) has them. All are MIT licensed; each folder keeps
its upstream LICENSE. None needs a login, an API key or payment. Vetted on
2026-11-16: markdown reference files only, no executable scripts.

Notes
- The `social-media-skills` pack mentions its author's scheduler (WoopSocial)
  in places. It is not needed; Meta Business Suite schedules for free.
- Some reference files list optional paid generators (image, video, voice).
  They are only examples. Ask before using anything that needs a key.
- To update a skill, copy the folder again from the source repo and update the
  commit in this table.
